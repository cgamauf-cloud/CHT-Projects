  • Clean-room design using published manufacturer data and the CHT calculation catalog (Phase 3). Formula IDs on AV-601.
  • Room 24′ L × 18′ W; ceiling 9′ is an assumption. Finished-face dimensions to be field-verified.

  • Equipment rack outside the theater beyond the back wall; door on the back wall at the right aisle.
  • Placement windows from Dolby home-theater guidance as commonly cited; verify against the current Dolby document.

Design review flags

  • Front-row vertical angle to image top 16.3 deg (>15 deg guidance [verify]).
  • Standing 1.80 m person on riser reaches 2.26 m; beam bottom there 2.24 m -> casts shadow when standing.
  • Subwoofers (4 x SSW-3): est. free-field max 114.4 dB vs LFE target 115 dB; relies on low-frequency room gain (not modelled).
  • Treated mid-band RT60 0.18 s is well below the ~0.26 s small-room reference: risk of an over-damped room. Trade some absorption for diffusion (e.g. rear half of side zones).
  • 125 Hz RT60 0.42 s vs mid-band 0.18 s: add low-frequency absorption.
  • Axial mode coincidence near 62.5 Hz: [0, 0, 1] and [2, 0, 0] (room ratios).
  • Axial mode coincidence near 93.8 Hz: [0, 4, 0] and [3, 0, 0] (room ratios).
  • Axial mode coincidence near 125.0 Hz: [0, 0, 2] and [4, 0, 0] (room ratios).
